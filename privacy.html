Privacy Policy

Last updated: 6 November 2026

Waenkun Daily AI News ("the app") is a personal tool used only with the channel owner's own TikTok account.

What the app accesses

  • user.info.basic: required by TikTok Login Kit to identify the connected account.
  • video.upload: to send the daily video to that account's inbox as a draft.

The app does not read followers, messages, comments, analytics or any other account data.

What is stored

Only the TikTok refresh token for the owner's account, kept as an encrypted secret in the owner's private GitHub repository so the daily job can upload. No data about other TikTok users is collected or stored.

Sharing

No data is sold or shared with third parties. Videos are sent only to TikTok.

Removing access

The account owner can revoke the app's access at any time in TikTok's settings for connected apps, and delete the stored token from the GitHub repository.
